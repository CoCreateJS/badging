CoCreate Badging

Set or clear the installed web app's icon badge from JavaScript or CoCreate Actions. Keep the badge tied to unread or other attention-worthy app state.

JavaScript API

await CoCreate.badging.setBadge(3);
await CoCreate.badging.setBadge(); // dot badge
await CoCreate.badging.clearBadge();

Actions

<button actions="badging.setBadge(3)">Set count</button>
<button actions="badging.clearBadge">Clear badge</button>

The API-only entry can also be imported by a service worker, while the main module registers Actions for page declarative use.
